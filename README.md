# ReVanced GIF Comments

YouTube **20.40.45**에서 Tenor GIF 댓글·답글을 작성하기 위한 커스텀 ReVanced 패치입니다.

**0.2.0은 GIF 버튼·검색 패널을 추가한 실험용 수정 버전입니다.** 0.1.0은 사용자의 기기 테스트에서 마커가 그대로 게시되는 문제가 확인되어 사용 중단으로 표시했습니다. 새 버전은 GIF ID를 댓글 본문에 넣지 않고 별도 초안 상태에 보관하며, 실제 Cronet 전송 직전 JSON의 `tenorId` 또는 protobuf field 32에 주입합니다. 새 버전도 기기에서 GIF 게시 성공까지 확인하지 못했습니다.

## 다운로드

- [릴리스 파일](https://github.com/mabinewb/revanced-gif-comments/releases/tag/v0.2.0)
- 번들: `gif-comments-0.2.0.rvp`
- Manager에 추가할 원격 소스:

```text
https://raw.githubusercontent.com/mabinewb/revanced-gif-comments/main/patches-bundle.json
```

## ReVanced Manager에서 불러오기

ReVanced Manager **2.6.0**의 소스 구조를 기준으로 작성했습니다. 실제 Manager 화면에서의 조작은 아직 검증하지 못했으며, 언어와 버전에 따라 명칭이 다를 수 있습니다.

1. Manager의 패치 번들 목록을 열고 **Add patches / 패치 추가**를 누릅니다.
2. **Enter URL / URL 입력**을 선택하고 위 `patches-bundle.json` 주소를 입력합니다. GitHub 저장소 페이지 주소나 `.rvp` 직접 다운로드 주소를 이 칸에 넣지 않습니다.
3. 원격 등록이 되지 않으면 릴리스의 `.rvp` 파일을 휴대폰에 다운로드하고 **Select from storage / 저장소에서 선택**으로 추가합니다.
4. 패치할 앱으로 원본 **YouTube 20.40.45 APK**를 선택합니다.
5. 사용할 공식 패치들과 함께 **GIF comments**를 직접 선택합니다. 실험용이므로 기본 선택되어 있지 않습니다. 기존 0.1.0의 패치된 APK를 다시 패치하지 말고 원본 APK로 다시 만드세요.
6. 패치·설치합니다. 기존 ReVanced 앱을 업데이트한다면 같은 Manager 서명 키를 사용해야 합니다. 비루팅 설치에서는 평소 사용하는 GmsCore support 등의 공식 패치도 필요합니다.

이 번들은 GIF 패치 하나만 포함합니다. 광고 차단·재생 관련 공식 패치를 대체하지 않습니다. 공식 번들과 함께 적용한 전체 조합은 아직 테스트하지 않았습니다.

## 댓글 작성

1. 동영상의 새 댓글 또는 답글 작성란을 엽니다.
2. 입력란 오른쪽의 **GIF** 버튼을 누릅니다.
3. 하단 **Tenor GIF 검색** 창에서 검색어를 입력하고 원하는 GIF를 선택합니다. 입력을 잠시 멈추면 검색하며, 이전 검색의 늦은 결과는 무시합니다.
4. 입력란 아래에서 선택한 GIF의 애니메이션 미리보기를 확인합니다. **제거** 버튼으로 선택을 취소할 수 있습니다. 댓글 텍스트도 함께 작성할 수 있습니다.
5. 유튜브의 원래 게시 버튼을 누릅니다. 다른 계정이나 원본 앱에서도 실제 GIF가 보이는지 확인하세요.

**`[[gif:…]]`를 직접 입력하지 마세요.** 수동 마커는 지원을 중단하고, 확인한 네이티브 댓글 요청 및 Cronet 댓글 전송 경로에서 차단합니다. 알 수 없는 전송 경로까지 차단을 보장할 수는 없습니다.

GIF 첨부 요청을 확인하지 못하면 약 10초 뒤 안내가 표시될 수 있습니다. 이 경우 텍스트만 게시되었을 가능성도 있으므로 댓글을 확인하세요. 텍스트 없이 GIF만 선택했을 때는 게시 버튼 활성화를 위한 보이지 않는 자리 문자를 사용하며, 지원하는 전송 경로에서 제거합니다. 서버가 추가 필드를 무시하거나 다른 전송 경로를 쓰면 첨부가 실패할 수 있습니다.

**기존 댓글 편집·커뮤니티 글은 지원하지 않습니다.** 다른 작성창을 열거나 입력란이 닫히면 이전 선택 정보가 다른 초안으로 전달되지 않도록 해제합니다. 임의 GIF 파일 업로드, Giphy, 즐겨찾기는 지원하지 않습니다. Tenor 페이지가 등급 정보를 제공하지 않는 결과도 있으므로 일부 GIF는 YouTube에서 거절될 수 있습니다.

## 실패 시 확인

- 목록에 패치가 없다면 번들을 새로 고침하거나 파일 가져오기를 사용합니다. 구형 Manager 1.x는 지원 대상으로 검증하지 않았습니다.
- 호환되지 않는 앱 버전 메시지가 나오면 20.40.45를 사용합니다. 호환성 검사를 강제로 무시하지 않습니다.
- 일반 댓글은 되지만 GIF가 없다면 attachment field 32의 서버 처리 여부를 확인해야 합니다. 계정·영상별 허용 여부도 정적 분석으로 알 수 없습니다.
- 문제를 보고할 때 앱 버전, Manager 버전, 선택한 패치와 표시된 오류를 알려주세요. 계정 쿠키·토큰·댓글 요청 원문은 공유하지 마세요.

## 빌드

Python 3.10+와 Java 21만 필요합니다. Android SDK나 GitHub Packages 토큰은 필요하지 않습니다.

```text
python tools/build.py
```

빌드 도구와 Android API 28 플랫폼을 공식 배포처에서 다운로드하고 `tools/dependencies.json`의 SHA-256으로 확인합니다. 결과는 `build/gif-comments-0.2.0.rvp`와 `build/SHA256SUMS.txt`입니다. 번들에는 JVM 클래스와 Android DEX, APK에 주입할 확장 DEX가 함께 들어 있습니다.

## 검증 범위와 설계

[검증 기록](docs/VALIDATION.md)을 참고하세요. 사용자 계정 정보나 네트워크 인증을 직접 읽지 않으며, 별도 서버나 API 키를 사용하지 않습니다. 유튜브 APK, 패치된 APK, 로그인 정보와 서명 개인 키는 이 저장소에 포함하지 않습니다.

아이디어와 웹 구현 참고: [rayytor/desktop_gifs](https://github.com/rayytor/desktop_gifs). 본 저장소의 요청 변환 코드는 Android protobuf 경로에 맞춰 새로 작성했습니다.
